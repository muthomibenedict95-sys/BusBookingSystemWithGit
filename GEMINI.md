# Bus Booking System

## Project Rules

- This is a Java + MariaDB bus booking system.
- Do not modify files unless explicitly asked.
- Do not inspect unrelated files or directories.
- Keep changes narrowly focused on the current task.
- Do not create or rewrite an entire feature unless explicitly requested.
- Explain important changes before making them.
- Prefer simple, beginner-friendly Java.
- Do not introduce frameworks or libraries unless explicitly requested.
- Preserve existing code unless a change is necessary.
- Ask before making broad architectural changes.
## Git and Agent Workflow

- Git is part of the project's development workflow.
- Work on the appropriate Git branch for the current task.
- Perform one task at a time.
- Keep each task narrowly scoped and independently reviewable.
- Do not combine unrelated features, fixes, refactoring, or cleanup in one task.
- Before making changes, inspect only the files relevant to the current task.
- Explain the intended changes before modifying files.
- Use agent capabilities deliberately, but keep agent actions constrained to the current task and project scope.
- Do not create branches, commit, merge, push, reset, revert, or otherwise modify Git history unless explicitly asked.
- After making changes, summarize what changed and why.
- Do not modify unrelated files even if improvements are noticed.
- Prefer small changes that can be reviewed with `git diff`.

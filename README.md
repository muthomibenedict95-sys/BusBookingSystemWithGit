# Bus Booking System

A beginner-friendly Java desktop application for managing bus bookings, routes, and passengers using a MariaDB database.

## Project Structure

- `src/main/java`: Application source code.
- `src/test/java`: Unit and integration tests.
- `resources/`: Configuration, SQL scripts, and static assets.
- `docs/`: Design and architectural documentation.

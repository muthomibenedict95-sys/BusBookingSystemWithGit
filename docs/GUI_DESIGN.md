# GUI Design Plan

## Window Management
- The application will use separate windows for different tasks (e.g., Search Window, Results Window, Booking Details Window).

## Bus Seat Layout
The seat selection interface will feature a realistic layout:
- **Front:** Driver's seat and Entrance Door.
- **Middle:** Central walkway.
- **Sides:** Paired seats (2 on each side of the walkway).
- **Rear:** A five-seat bench across the back.

## Navigation Flow
1. **Route Selection:** Dropdowns for Location A-K and a Date Picker.
2. **Bus Selection:** List of available schedules for the chosen route.
3. **Seat Selection:** Interactive grid representing the realistic layout.
4. **Confirmation:** Summary of booking and final submission.
